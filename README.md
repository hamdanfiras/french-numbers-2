# Nombres à l’Oreille

Application Flutter hors ligne pour s’entraîner à reconnaître les nombres parlés en français.

## Développement

```sh
flutter pub get
flutter run
```

## Vérification

```sh
flutter analyze
flutter test
```

Les fichiers audio de `assets/audio/` sont inclus dans l’application. Aucune connexion réseau n’est utilisée pendant l’entraînement.
